# RBook 与小红书类产品的差距分析

更新日期：2026-08-02

## 现有能力判断

RBook 已经越过了“图片瀑布流 Demo”阶段，具备一套可以运行的社区主链路：

- 图片笔记发布、草稿自动保存、公开与私密可见性
- 推荐、关注、最新三类信息流和无限滚动
- 搜索笔记、用户和话题
- 点赞、收藏、评论线程、关注关系和通知中心
- 创作者公开主页、个人中心和数据中心
- 内容负反馈、举报、审核后台和权限控制
- Supabase RLS、私密图片 Bucket、访问日志和 GitHub Actions 健康检查

因此，接下来不应该继续只增加零散按钮，而应补齐“内容组织、创作资产、深度社交、治理和商业场景”。

## 本轮已完成：话题社区层

### 热议话题

- 从公开笔记标签中动态聚合话题。
- 综合近期发布量、浏览、点赞、收藏、评论和时间新鲜度计算热度。
- 发现页不再使用硬编码标签。

### 独立话题页

- 新路由：`/topic/:topicName`。
- 支持热门、最新排序。
- 支持无限滚动、相关热议榜和发布入口。
- 话题只聚合公开、正常发布且未隐藏的笔记。

### 关注话题

- 新增 `topic_follows` 表和 RLS。
- 用户只能查看、创建和删除自己的话题关注关系。
- 关注话题会进入推荐算法，相关笔记得到额外加权。
- 推荐理由会显示“关注话题 #话题名”。

## 下一阶段建议

### 第一阶段：创作资产闭环

1. 服务端草稿箱和跨设备恢复。
2. 编辑已发布笔记。
3. 公开与私密转换，并安全迁移图片 Bucket。
4. 定时发布和发布失败恢复。
5. 视频笔记第一版。

验收指标：草稿恢复成功率、发布成功率、创作完成率、发布耗时。

### 第二阶段：安全社交闭环

1. 用户拉黑和静音。
2. @提及和提及通知。
3. 私信会话与消息请求。
4. 仅关注者评论、私密账号和关注审批。
5. 评论与私信频率限制。

验收指标：有效对话率、举报率、骚扰拦截率、通知点击率。

### 第三阶段：推荐与搜索深化

1. 服务端曝光去重。
2. 会话级作者和话题多样性重排。
3. 搜索联想、历史搜索和热门搜索。
4. 冷启动兴趣选择。
5. 推荐权重 A/B 测试。

验收指标：有效打开率、停留时长、收藏率、关注率、负反馈率和次日留存。

### 第四阶段：垂直场景

在社区内容和留存达到稳定规模后，再选择一个垂直方向：

- 本地生活与地点页；或
- 工具、知识管理和学习实验；或
- 独立创作者产品与服务展示。

不建议当前直接复制完整电商和直播体系，这两部分需要支付、履约、风控、资质审核和大规模实时基础设施，成本远高于普通社区功能。
